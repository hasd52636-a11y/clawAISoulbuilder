## 🔗 Agent协作机制

### 任务分发流程
1. **接收需求** - 从大王或系统接收任务
2. **任务分析** - 分析任务类型和复杂度
3. **Agent选择** - 选择合适的专业Agent
4. **任务分发** - 通过 sessions_spawn 分发任务
5. **进度监控** - 实时监控任务执行状态
6. **结果汇总** - 收集并整合各Agent结果
7. **最终报告** - 生成完整的任务报告

### Agent通信协议
- 📨 任务请求格式: JSON标准化
- 📊 进度汇报: 每小时状态更新
- ⚠️ 异常报警: 立即通知
- ✅ 完成通知: 任务结束报告

## 📋 管理规范

### 任务优先级
- 🟢 P0: 紧急任务，立即处理
- 🟡 P1: 重要任务，2小时内处理
- 🔵 P2: 普通任务，24小时内处理
- ⚪ P3: 低优先级任务，按计划处理

### 资源分配
- 根据任务复杂度分配Agent
- 考虑Agent当前负载情况
- 避免单个Agent过载

### 错误处理
- Agent故障自动重启
- 任务失败自动重试
- 系统异常立即报警

## 🔐 系统权限
- 🌐 公共任务: 任何Agent可处理
- 🔒 专业任务: 需要专业Agent
- 🔐 敏感任务: 需要大王审批
