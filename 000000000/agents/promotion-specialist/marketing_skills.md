# 🚀 营销增长技能详解

## 🎯 核心营销技能（来自热度排行榜）

### 1. audit-website (网站审计) - 21.8K热度
**功能**: 全面分析网站健康状况
**应用场景**:
- 网站技术性能审计
- 用户体验评估
- 内容质量分析
- 安全漏洞检查

**关键指标**:
- 页面加载速度
- 移动端适配性
- SEO基础评分
- 安全性评级

### 2. seo-audit (SEO分析) - 20.8K热度  
**功能**: 搜索引擎优化分析和建议
**应用场景**:
- 关键词策略优化
- 内容SEO优化
- 技术SEO问题修复
- 竞争对手SEO分析

**关键能力**:
- 关键词研究和布局
- 元标签优化
- 内部链接结构优化
- 外部链接质量评估

### 3. product-marketing-context (产品营销) - 9.5K热度
**功能**: 产品卖点和用户痛点梳理
**应用场景**:
- 产品价值主张提炼
- 目标用户痛点分析
- 竞争优势定位
- 营销信息架构设计

**核心输出**:
- 产品核心价值清单
- 用户痛点映射表
- 差异化竞争优势
- 营销话术模板

### 4. page-cro (转化率优化)
**功能**: 页面转化率优化和分析
**应用场景**:
- 落地页优化
- 用户转化路径优化
- A/B测试设计
- 用户体验改进

## 🔧 技能使用指南

### 执行流程
1. **需求分析** - 明确营销目标
2. **数据收集** - 收集相关数据
3. **分析评估** - 使用相应技能分析
4. **建议提出** - 提供优化建议
5. **效果跟踪** - 监控改进效果

### 工具搭配
- `web_fetch`: 用于网站数据抓取
- `browser`: 用于页面性能测试
- `feishu_bitable_list_records`: 用于数据统计
- `canvas`: 用于数据可视化

### 最佳实践
1. **定期审计** - 每月执行一次网站审计
2. **持续优化** - 基于数据持续改进
3. **竞品对比** - 定期分析竞争对手
4. **用户反馈** - 结合用户反馈优化

## 📊 绩效衡量

### 关键指标
- **网站流量** - 有机流量增长
- **转化率** - 转化率提升幅度
- **排名提升** - 关键词排名进步
- **用户体验** - 用户满意度提升

### 成功案例
- 通过SEO审计提升有机流量30%
- 通过CRO优化提高转化率25%
- 通过产品营销优化提升用户认知
