# 🚀 产品分析标准工作流程

## 📋 分析流程

### 1. 信息收集阶段
```bash
# 自动收集产品信息
- 网页内容抓取和分析
- 技术规格提取
- 价格信息收集
- 供应商信息获取
- 用户评价分析
```

### 2. 市场分析阶段  
```bash
# 市场调研和分析
- 竞品对比分析
- 市场定位评估
- 价格竞争力分析
- 目标用户分析
- 市场趋势研究
```

### 3. 风险评估阶段
```bash
# 风险和价值评估
- 产品质量风险评估
- 供应商可靠性评估
- 市场接受度预测
- 投资回报率分析
- 潜在问题识别
```

### 4. 报告生成阶段
```bash
# 生成完整分析报告
- 执行摘要
- 详细数据分析
- 可视化图表
- 具体建议
- 风险提示
```

## 🛠️ 可用工具

### 网络工具
- `web_search_exa` - 实时网络搜索
- `browser` - 浏览器自动化
- `web_fetch` - 网页内容获取

### 分析工具  
- `data_analysis` - 数据分析
- `market_analysis` - 市场分析
- `risk_assessment` - 风险评估

### 报告工具
- `report_generator` - 报告生成
- `data_visualization` - 数据可视化

## 📊 报告标准格式

### 必须包含章节
1. **产品基本信息**
2. **技术规格分析**
3. **市场价格分析**
4. **竞品对比分析**
5. **供应商评估**
6. **市场前景预测**
7. **采购建议**
8. **风险提示**

### 数据要求
- ✅ 基于事实和数据
- ✅ 引用可靠来源
- ✅ 提供具体数字
- ✅ 对比分析
- ✅ 可视化展示

## ⚡ 响应标准

### 接收任务后
- 立即确认接收任务
- 开始信息收集工作
- 定期汇报进度
- 在2小时内完成初步分析
- 在4小时内提供完整报告

### 遇到问题
- 立即报告遇到的问题
- 提供替代方案
- 请求必要的信息
- 不隐瞒任何限制
