# OpenClaw 技能安装指南

## 安装 ClawHub CLI
```bash
npm install -g clawhub
```

## 🎯 必选技能（核心功能）

### 基础工具类
```bash
clawhub install file-manager          # 文件管理器
clawhub install find-skills-skill     # 技能发现工具
clawhub install skill-creator         # 技能创建器
```

### 开发工具类
```bash
clawhub install coding-agent-backup   # 编程代理备份版
clawhub install frontend-design-3     # 前端设计v3
clawhub install code-refactor         # 代码重构工具
clawhub install test-driven-development # 测试驱动开发
clawhub install api-integration       # API集成工具
```

### 自动化工具类
```bash
clawhub install autoclaw-browser      # 浏览器自动化
clawhub install web-crawler           # 网页抓取工具
```

### 内容管理类
```bash
clawhub install documentation         # 文档技能
clawhub install file-organizer        # 文件整理器
```

## 💡 安装建议
1. 先安装**必选技能**建立基础功能
2. 根据需求选择**可选技能**
3. 使用 `clawhub list` 查看已安装技能
