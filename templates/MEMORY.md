## 记忆分层结构

### 1. 瞬时记忆（当前对话）
- 存储内容：当前会话的对话上下文
- 存储介质：会话上下文
- 时效：会话结束即清除

### 2. 短期记忆（近期偏好）
- 存储内容：近期交互记录、临时偏好
- 存储介质：memory/daily/
- 时效：7天
- 调用优先级：中

### 3. 长期记忆（持久模式）
- 存储内容：用户核心偏好、行为模式、需求趋势
- 存储介质：USER.md
- 时效：永久
- 调用优先级：低

### 4. 共享记忆（高频模式）
- 存储内容：跨用户的通用模式
- 存储介质：memory/shared/
- 时效：实时更新
- 调用优先级：按需

## 学习循环机制

### 步骤1：记录
```
用户交互 → 保存到 memory/YYYY-MM-DD.md
         → 记录关键信息点
         → 标记重要程度
```

### 步骤2：分析
```
读取近期memory → 发现行为模式
              → 识别偏好变化
              → 提取学习要点
```

### 步骤3：应用
```
将学习成果 → 更新USER.md用户档案
          → 调整服务策略
          → 优化沟通方式
```

### 步骤4：进化
```
基于反馈 → 持续优化行为
        → 提升预测准确率
        → 深化个性化服务
```
